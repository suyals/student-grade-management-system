1. Encapsulation

Implemented in SubjectMarks and Student using private fields, strict numerical validation range (0-100), and controlled accessor/mutator methods.

2. Inheritance

Student inherits common personal properties (id, name, email) from the abstract base class Person.

3. Polymorphism

Achieved through GradingStrategy interface implementations, method overriding (getRoleDescription()), and Comparable<Student> natural rank ordering.

4. Abstraction

Abstract Person class and GradingStrategy interface hide internal GPA formulas, evaluation logic, and validation complexity from callers.
